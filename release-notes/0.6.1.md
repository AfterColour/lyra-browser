A fix for YouTube freezing on the first start after the update.

**Download:** `LyraSetup.exe` below. Lyra 0.6.0 updates itself: the new version downloads in the
background and installs the next time Lyra starts (Settings > About).

- **Fixed:** on the first start after an update (or a fresh install) the first page with video,
  YouTube above all, could freeze for a long while: it was preparing Lyra's video components
  itself, all of them at once. The installer now prepares them before Lyra starts, so video pages
  open right away.

---

Исправление: YouTube больше не зависает при первом запуске после обновления.

**Скачать:** `LyraSetup.exe` ниже. Lyra 0.6.0 обновляется сама: новая версия загружается в фоне
и устанавливается при следующем запуске Lyra (Настройки > О программе).

- **Исправлено:** при первом запуске после обновления (или новой установки) первая страница с
  видео, прежде всего YouTube, могла надолго застыть: она сама готовила все видеокомпоненты Lyra
  разом. Теперь их готовит установщик до запуска Lyra, и страницы с видео открываются сразу.
