The first public version of Lyra.

**Download:** `LyraSetup.exe` below. It installs for your Windows user only and asks for no
administrator rights. Windows SmartScreen may warn about an unknown publisher the first time:
choose "More info" > "Run anyway".

- Tabs next to the address, in their own row or down the side; split view; pinned tabs
- Command palette (Ctrl+K), reader view, translation, picture in picture
- Video through GStreamer with Direct3D 11 (YouTube and other sites)
- Spell checking in English and Russian, ad blocker, passwords, private tabs

Первая публичная версия Lyra.

**Скачать:** `LyraSetup.exe` ниже. Устанавливается только для вашего пользователя Windows и не
просит прав администратора. Windows SmartScreen при первом запуске может предупредить о неизвестном
издателе: нажмите «Подробнее» → «Выполнить в любом случае».

- Вкладки рядом с адресом, отдельной строкой или сбоку; разделённый экран; закреплённые вкладки
- Палитра команд (Ctrl+K), режим чтения, перевод страниц, картинка в картинке
- Видео через GStreamer и Direct3D 11 (YouTube и другие сайты)
- Проверка орфографии на русском и английском, блокировщик рекламы, пароли, приватные вкладки

`lyra-0.1.0-lgpl-sources.zip` — source code of the LGPL libraries in this version (исходники библиотек под LGPL).
