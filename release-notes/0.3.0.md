Extensions from Chrome Web Store and Firefox Add-ons, themes, and a smoother browser.

**Download:** `LyraSetup.exe` below. Lyra 0.2.0 updates itself: the new version downloads in the
background and installs the next time Lyra starts (Settings > About).

- **Extensions:** open an extension's page in Chrome Web Store or Firefox Add-ons and press
  "Add to Lyra" - Lyra asks first and shows what the extension will be able to do. They get a
  button on the toolbar with their pop-up and badge, can change pages, run in the background and
  block with their own network rules: uBlock Origin Lite, Dark Reader and others work. Manage
  them in Settings > Extensions. Not there yet: webRequest (the full uBlock Origin), context
  menu items, bookmarks and history for extensions.
- **Themes:** install themes from the themes.vivaldi.net catalog or from a file, keep several,
  and choose what each one changes: colours, accent, the start page picture. Lyra is not
  affiliated with Vivaldi Technologies; the themes are made by their authors.
- **Menus:** the toolbar, tab and page menus now look like the rest of Lyra.
- **Smoother:** scrolling no longer stutters on some pages; the night sky on the start page no
  longer slows the window down; Settings no longer freeze on pages with theme pictures.
- **Fixes:** toolbar icons show on Windows 10; a crash when closing an extension's pop-up.

Расширения из Chrome Web Store и Firefox Add-ons, темы и более плавный браузер.

**Скачать:** `LyraSetup.exe` ниже. Lyra 0.2.0 обновится сама: новая версия скачается в фоне и
установится при следующем запуске Lyra (Настройки > О программе).

- **Расширения:** откройте страницу расширения в Chrome Web Store или Firefox Add-ons и нажмите
  «Установить в Lyra» - Lyra сначала спросит и покажет, что расширение сможет делать. У них есть
  кнопка на панели со всплывающим окном и значком, они могут изменять страницы, работать в фоне и
  блокировать запросы своими сетевыми правилами: работают uBlock Origin Lite, Dark Reader и
  другие. Управление - в Настройках > Расширения. Пока нет: webRequest (полный uBlock Origin),
  пунктов расширений в контекстном меню, закладок и истории для расширений.
- **Темы:** устанавливайте темы из каталога themes.vivaldi.net или из файла, держите несколько и
  выбирайте, что меняет каждая: цвета, акцент, картинку стартовой страницы. Lyra не связана с
  Vivaldi Technologies; темы созданы их авторами.
- **Меню:** меню панели, вкладок и страниц теперь в стиле Lyra.
- **Плавнее:** прокрутка больше не подтормаживает на некоторых страницах; звёздное небо на
  стартовой странице больше не замедляет окно; настройки не зависают на разделах с картинками тем.
- **Исправления:** значки панели видны в Windows 10; падение при закрытии всплывающего окна
  расширения.
