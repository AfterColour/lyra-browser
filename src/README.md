# Исходники Lyra

Каждый модуль — пара `.h` (что модуль даёт остальным) и `.cpp` (как это сделано).
Всё, что объявлено `static` в `.cpp`, — внутреннее дело этого файла.

| Папка | Файл | За что отвечает |
|---|---|---|
| `common/` | `Platform.h` | системные заголовки, GDI+, WebKit C API (общий предкомпилированный заголовок) |
| `core/` | `Constants.h` | размеры, идентификаторы, сообщения окна, команды |
| | `Settings` | настройки, `settings.ini`, папка профиля |
| | `StringUtils` | UTF-8/UTF-16, строки WebKit, экранирование HTML/JS |
| | `Url` | ввод в адресной строке → адрес или поиск |
| | `Localization` | язык интерфейса: `Tr(L"English", L"Русский")` |
| `app/` | `Log` | журнал `tabs.log` |
| | `CrashHandler` | запись падения в журнал |
| | `Environment` | переменные `LYRA_*`, GStreamer |
| `browser/` | `Tab.h` | структура вкладки |
| | `TabManager` | создать / закрыть / переключить вкладку, навигация |
| | `PageClients` | колбэки WebKit: загрузка страницы, сбои, диалоги JS, выбор файла |
| | `Downloads` | загрузки |
| | `WebContext` | контекст WebKit, профиль, настройки движка |
| | `StartPage` | стартовая страница, экран приветствия, команды `lyra://` |
| | `History` | история посещений, часто посещаемые сайты |
| `ui/` | `MainWindow` | главное окно |
| | `Chrome` | панель вкладок и инструментов: раскладка, отрисовка, мышь |
| | `AddressBar` | поле адреса |
| | `Suggestions` | подсказки под адресной строкой |
| | `Theme` | цвета, акцент, тёмная тема |
| | `Animation` | часы анимаций (кадры в такт экрану) |
| | `WindowFrame` | окна без системного заголовка |
| | `Draw` | общие функции рисования |
| | `FullScreen` | полноэкранный режим |
| | `Commands` | горячие клавиши, меню |
| | `Dialogs` | диалог ввода текста |
| `ui/settings/` | `SettingsModel` | строки и страницы окна настроек |
| | `SettingsPages` | содержимое разделов |
| | `SettingsWindow` | само окно настроек |

`main.cpp` — только точка входа `wWinMain`.

Новый файл в `src/` подхватывается сборкой сам (`build.bat`), править `CMakeLists.txt` не нужно.

Страницы самого браузера (стартовая, приветствие, шаблон истории) лежат в `../resources/` и при сборке копируются в `run\resources\`.
